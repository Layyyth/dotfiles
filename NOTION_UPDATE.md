# Layth's Development Setup

## Terminal (Zsh) Quick Reference

### Single Terminal Window Management

| Action | Command |
|--------|---------|
| New terminal tab | `Ctrl + Shift + t` |
| Close tab | `Ctrl + Shift + w` |
| Next tab | `Ctrl + PageDown` |
| Previous tab | `Ctrl + PageUp` |
| Go to tab 1-9 | `Alt + 1` through `Alt + 9` |

## Neovim Quick Reference

### Tree (File Explorer)

| Action | Keybinding |
|--------|------------|
| **Open tree** | `Ctrl + e` or `Space + e` |
| **Close tree** | `Ctrl + e` (toggle) |
| Move in tree | Arrow keys |
| Open file | `Enter` |
| Close file | `q` |

### Terminal Windows (inside Neovim)

| Action | Keybinding |
|--------|------------|
| **Open vertical terminal** | `Ctrl + n` |
| **Open horizontal terminal** | `Ctrl + h` |
| **Open floating terminal** | `Ctrl + f` |
| **Close terminal** | `Ctrl + n` (toggle) |
| **Exit terminal mode** | `Esc` |

### Window Navigation

| Action | Keybinding |
|--------|------------|
| Move **left** | `Ctrl + h` |
| Move **down** | `Ctrl + j` |
| Move **up** | `Ctrl + k` |
| Move **right** | `Ctrl + l` |

### Terminal Window Sizes

| Keybinding | Size |
|------------|------|
| `Ctrl + n` | Vertical (50% width) |
| `Ctrl + h` | Horizontal (15 rows) |
| `Ctrl + f` | Floating (30% screen) |

## Quick Summary

### Opening Tools
1. **Tree**: Press `Ctrl + e`
2. **Terminal**: Press `Ctrl + n`

### Closing Tools
1. **Tree**: Press `Ctrl + e` again
2. **Terminal**: Press `Ctrl + n` again

### Moving Between Windows
- Use `Ctrl + h/j/k/l` to move between any split windows
